# PARDIK SMART IPTV — نسخه ویندوز ۱۰ (۶۴ بیتی)

بازطراحی کامل و مستقلِ نرم‌افزار اندرویدی `PARDIK SMART IPTV`
(بسته `com.dexin.wanchuan.iptv3`، نسخه 2.7.1.71) برای ویندوز ۱۰ x64.
این نسخه از روی خودِ فایل APK مهندسی معکوس شده و همان قرارداد شبکه، همان
تنظیمات پیش‌فرض، همان صفحه‌ها و همان ظاهر را پیاده‌سازی می‌کند.

> گزارش کامل مهندسی معکوس: `../analysis/REVERSE_ENGINEERING_REPORT.md`

---

## ۱) آنچه دریافت می‌کنید
- **یک نرم‌افزار واقعی و قابل نصب برای ویندوز ۱۰ x64** — بدون نیاز به اندروید،
  بدون شبیه‌ساز، بدون وابستگی سنگین.
- رابط کاربری تلویزیونی (مانند نسخه اندروید) در یک پنجرهٔ مستقلِ بدون نوار مرورگر
  (حالت Edge App) با پیمایش کامل با کیبورد/ریموت (جهت‌ها، Enter=OK، Esc=بازگشت).
- زبان‌ها: **فارسی (پیش‌فرض)**، English، 中文 — دقیقاً مانند منابع خود APK.
- تمام آیکون‌ها، پس‌زمینه‌ها و تصاویر اصلیِ APK استخراج و استفاده شده‌اند.

## ۲) نیازمندی‌های سخت‌افزاری (مطابق دستگاه مقصد شما)
| مورد | حداقل | وضعیت روی ASUS X550CC شما |
|---|---|---|
| سیستم‌عامل | Windows 10 64-bit | ✔ Home 64-bit |
| پردازنده | هر x64 دو هسته‌ای | ✔ i5-3337U |
| RAM | 2 GB | ✔ 6 GB |
| گرافیک | بدون نیاز به شتاب سخت‌افزاری | ✔ GT 720M / HD 4000 (رمزگشایی ویدئو توسط مرورگر/سخت‌افزار انجام می‌شود) |
| دیسک | ~150 MB | ✔ |

مصرف CPU/RAM پایین است زیرا:
- پخش ویدئو با رمزگشایی سخت‌افزاری مرورگر (Media Foundation / DXVA) انجام می‌شود.
- برای منابع RTSP/UDP/MPEG-TS، یک **remux سبک با `-c copy`** (بدون رمزگشایی مجدد)
  توسط FFmpeg انجام می‌شود → تقریباً صفر درصد CPU.
- بک‌اند فقط کتابخانهٔ استاندارد پایتون است (هیچ وابستگی اضافه‌ای نصب نمی‌شود).

## ۳) نصب (بدون هیچ دانش فنی)
1. پوشه را از زیپ خارج کنید (هر جا، مثلاً `C:\PARDIK`).
2. روی **`install\Setup.bat`** دوبار کلیک کنید.
   - برنامه در `%LOCALAPPDATA%\PARDIK-SMART-IPTV` کپی می‌شود.
   - میان‌بر دسکتاپ و منوی استارت ساخته می‌شود.
   - در بخش Add/Remove Programs قابل حذف خواهد بود.
   - اگر پایتون نصب نباشد، به‌صورت خودکار یک پایتون رسمیِ embeddable دانلود و
     در پوشهٔ برنامه قرار می‌گیرد (نیاز به نصب دستی نیست).
   - FFmpeg (فقط برای کانال‌های RTSP/TS) به‌صورت خودکار از PyPI دریافت می‌شود.
3. برنامه خودکار اجرا می‌شود. برای اجرای مجدد روی میان‌بر دسکتاپ
   **«PARDIK SMART IPTV»** دوبار کلیک کنید.

> اگر اینترنت در دسترس نبود: کافی است یک‌بار روی دستگاهی با اینترنت Setup را
> اجرا کنید؛ پوشهٔ نصب‌شده کاملاً آفلاین و قابل کپی است.

### حذف نصب
`install\Uninstall.bat` یا از مسیر Settings → Apps → PARDIK SMART IPTV.

## ۴) تنظیمات پیش‌فرض (مطابق فایل اصلی)
| مورد | مقدار پیش‌فرض |
|---|---|
| آدرس سرور | `10.21.0.10` |
| پورت سرور | `8030` |
| پورت RTSP | `554` |
| **رمز ورود به تنظیمات** | **`111999`** |
| مسیر API | `/iptv2/` و `/iptv2/manager/` (هر دو پشتیبانی می‌شود) |
| VOD | `/iptv2/vod/` |
| WebSocket کنترل | `ws://{ip}:{port}/dx-admin/websocket/{mac}` و `ws://{ip}:{port}/iptv2/websocket/{room}` |

تغییر IP/پورت/شماره اتاق: از منوی اصلی → **تنظیمات سیستم** → رمز `111999` →
ویرایش «آی‌پی سرور» / «پورت سرور» / «شماره اتاق».

## ۵) صفحه‌ها و امکانات (معادل نسخه اندروید)
- صفحه اتصال (Ping) → صفحه خوش‌آمد با انتخاب زبان، ساعت/تاریخ، آب‌وهوا، متن خوش‌آمدگویی مهمان
- صفحه اصلی: نوار بالا (لوگو، شماره اتاق، Wi-Fi، آب‌وهوا، ساعت) + منوی افقی آیکون‌ها
- **پخش زنده**: بسته‌ها → لیست کانال‌ها با شماره، نشان کانال، واترمارک، لیست کنار صفحه،
  علاقه‌مندی‌ها، وضعیت برنامه (EPG)، پروتکل‌های RTSP/HLS/HTTP/UDP
- **VOD**: دسته‌ها + گرید پوسترها + جزئیات (خلاصه/کارگردان/مدت/قیمت) + پخش با لیست
- **بازپخش (Timeshift/EPG)**، **مناظر**، **غذا/کترینگ**، **خدمات اتاق** (خدمتکاری، لباس،
  اقلام، بیدارباش، صورتحساب، تسویه حساب)، **معرفی هتل**، **موسیقی**، **صورتحساب مصرف**
- **تنظیمات** محافظت‌شده با رمز: شماره اتاق، IP، پورت، شبکه محلی، MAC، زبان، اتصال مجدد، نسخه

## ۷) عیب‌یابی سریع
- **«سرور قطع شد»**: IP/پورت را در تنظیمات بررسی کنید؛ سرور مجتمع باید در دسترس باشد.
- **کانال RTSP پخش نمی‌شود**: FFmpeg باید موجود باشد (به‌صورت خودکار نصب می‌شود؛
  یا دستی `tools\ffmpeg.exe` قرار دهید).
- **تصویر سیاه است ولی صدا هست**: کلید Enter را بزنید تا حالت تناسب تصویر عوض شود.
- لاگ بک‌اند: پنجرهٔ کنسول ندارد؛ برای دیدن خطاها `PARDIK-SMART-IPTV.bat` را اجرا کنید.
